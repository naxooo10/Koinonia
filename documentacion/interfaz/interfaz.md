# Diseño de interfaz de Koinonía

## Objetivo

Facilitar la gestión de Casas Iglesias, usuarios, reuniones y
asistencia mediante pantallas claras y una navegación consistente.

## Decisiones visuales

- Se utiliza azul como color principal para identificar las acciones.
- El fondo claro y el texto oscuro favorecen el contraste y la lectura.
- Se mantiene una tipografía consistente para títulos, textos y controles.
- Los botones, formularios y tarjetas conservan el mismo estilo.
- Los títulos y el espaciado permiten distinguir las secciones.

## Navegación y usabilidad

- El panel principal permite acceder a los módulos del sistema.
- En escritorio se utiliza un menú lateral; en móvil, un menú desplegable.
- Los formularios identifican los campos obligatorios y opcionales.
- Los errores indican qué información debe corregirse.
- Las confirmaciones informan el resultado de las acciones.
- Se incluyen estados vacíos y búsquedas sin resultados.
- En móvil, los registros se presentan como tarjetas para facilitar
  su lectura sin desplazamiento horizontal.

## Recorridos principales

1. Crear o editar una Casa Iglesia.
2. Activar o desactivar casas y usuarios.
3. Registrar una reunión y seleccionar sus asistentes.
4. Consultar informes por período y filtros adicionales.

## Alcance del prototipo

El prototipo utiliza datos ficticios y simula la navegación.
No guarda cambios en una base de datos.

Eventos y Materiales de estudio se presentan como funciones propuestas
para una etapa posterior de implementación.
